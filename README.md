# 日本の実質賃金停滞 — OECDデータで読む35年

OECD「Average annual wages」(1990–2025年、実質・自国通貨建て)を用いて、日本を含む主要8か国(韓国・米国・英国・豪州・フランス・カナダ・イタリア)の実質賃金の推移を比較した調査ノートの公開ページです。ドイツは系列が1991年開始(再統一後)のため対象外です。

もとになった調査ノート「日本の実質賃金停滞に関するノート — OECD平均年間賃金系列の定義と解釈上の留意点」は筆者作成・非公開であり、本リポジトリには含まれていません。

**公開ページ:** https://katzkawai.github.io/kklab-japan-real-wage-growth/

## 内容

- 実質平均年間賃金の1990年比変化率のインタラクティブなグラフ(8か国比較、各年の値をホバー/キー操作で表示)
- グラフを読むうえでの統計上の注意点(FTE調整・構成効果・デフレーターの違いなど)
- 日本経済の停滞についての分析

## ファイル

- `index.html` — 公開ページ本体(インタラクティブなグラフを含む)
- `japan_real_wage_growth.png` — グラフ静止画版(OECDデータより作成)
- `oecd_real_wage_growth_1990base.csv` — 元データ(1990年基準の累積変化率、%)

## 出所

OECD, Average annual wages (dataset: `DSD_EARNINGS@AV_AN_WAGE`), constant prices (2025 base), national currency units.
